# 이음

여자 아이돌의 그룹 활동 이력을 연결한 3D 지도입니다.

같은 멤버가 정식 활동한 그룹을 연결합니다. 그룹과 공유 멤버를 검색하고, 두 그룹 사이의 최단 경로와 출처를 볼 수 있습니다.

## 실행

Node.js 22 이상이 필요합니다.

```sh
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. 파일을 수정하면 다시 빌드되며, 브라우저를 새로고침하면 반영됩니다.

## 테스트와 빌드

```sh
npm test
npm run build
```

빌드 결과는 `dist/index.html`에 생성됩니다. 코드와 데이터를 포함한 단일 HTML 파일입니다.

## 데이터

`data/girl-group-graph.json`에 그룹, 공유 멤버, 출처가 있습니다. 조사 기록은 `docs/research-notes.md`에서 볼 수 있습니다.

2026년 9월 15일의 1차 조사 자료입니다. 연결을 찾지 못한 그룹도 포함하며, 모든 멤버의 활동 이력을 검증한 자료는 아닙니다.
